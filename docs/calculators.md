# Property calculators

The installed Aptly skill reference was used because `.skill-staging/aptly-website-features/references/calculators.md` was not present in this workspace.

- `/tools/rent-affordability`: household net monthly income divided by 2.5, matching the existing For Rent income guideline. Public Aptly inventory uses the existing company configuration. Rent amounts from the feed are cents; inputs and formula results are dollars. Only currently available homes within budget are shown. Income is neither persisted nor submitted. Feed failure links to the public Aptly portal.
- `/tools/rent-vs-sell`: includes a Google-verified property address and an email-results form. A successful submission creates a `NEW LEAD (M)` owner lead, emails the complete current assumptions and results through the configured Aptly inbox, and links the outbound email to the new card. The calculator includes editable selling costs, annual rent growth, and operating cost growth. Both scenarios are before tax, include selling costs, and account for mortgage payoff or negative amortization. Rental cash flow is not reinvested.
- `/tools/pm-fee-roi`: includes a Google-verified property address and an email-report form. A successful submission creates the owner lead first, sends the current inputs and results through the configured Aptly inbox, and links that outbound email to the new lead card. Configure `VITE_GOOGLE_MAPS_API_KEY` for browser suggestions, `GOOGLE_MAPS_API_KEY` for server verification, and the two `APTLY_EMAIL_*` sender values in the hosting environment.
- Existing Free Rental Analysis remains the owner follow-up. Owner requests now use the shared `/api/owner-lead` handler on the calculator and Free Rental Analysis pages. Each lead note records a server-controlled description of the submitted form, the originating page title, and a clickable page URL. Board schema and configuration are validated at submission time. The stage is `NEW LEAD (M)` and source is `Website`. A local ignored `.env.local` supplies credentials. Configure APTLY_API_TOKEN, APTLY_OWNER_LEADS_BOARD_ID, and APTLY_OWNER_LEADS_STAGE in the hosting environment before deployment. No live test lead has been submitted yet.

Navigation links are in Resources and the rental search page. Run `pnpm --filter @workspace/et-website-v1 test:calculators` for formula and currency-boundary checks.
